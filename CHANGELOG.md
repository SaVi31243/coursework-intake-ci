# Історія змін

## v1.3.0

Додано Flask Blueprint для приймання та читання робіт. Реєстр SQLite повертає номер після завершення транзакції. Повтор подання зберігає попередній номер.

## v2.3.0

Після транзакції сервіс імітує підтвердження з кодом ACK. Прапорець CONFIRMATION_ENABLED=0 спричиняє 503 після запису, зберігаючи номер подання і працездатність /health.
